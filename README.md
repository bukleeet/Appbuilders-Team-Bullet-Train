# WeekBack

Run `npm start`, then open http://localhost:3000. No dependencies or remote fonts required.

Initial UI: Today, Week, Tasks, Settings, manual task entry, local saving, progress updates, recovery preview and undo. AI and automatic scheduling are pending; demonstration recovery proposals are labeled. No cloud sync.

Code boundaries: src/store.js (data), src/app.js (UI), src/styles.css (design). Plans: IMPLEMENTATION-PLAN.md and UI-SPEC.md. Approved screenshots: docs/design. Old prototypes are preserved in archive and ignored.
